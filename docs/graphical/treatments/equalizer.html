The equalizer

Choose and manage profiles

Click Profile to open the searchable library. Choose a row, then Load. Unsaved edits stay with each profile when switching or restarting. New, Rename, Delete, Revert, Import and Export are available here.

Save deliberately, keep working edits

Save

Updates the current custom profile. An asterisk marks unsaved edits.

Save As

Name a copy. Built-in profiles use Save As so the original remains available.

Recover or revert

Working edits survive restarts. Revert restores the saved curve after confirmation.

Duplicate names and files changed elsewhere are protected. Naming errors stay in the form so you can correct them. Within the library: Ctrl+S saves, Ctrl+Shift+S opens Save As, Enter loads and Esc closes.
